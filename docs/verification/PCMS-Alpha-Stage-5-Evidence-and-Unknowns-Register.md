## 5. Smallest first verification frontier — Stage 5.1

Source review identifies a first-priority **registration-order hypothesis**: a PCMS event-page wake entrypoint must be installed before any awaited recovery. The donor installs `routing-gate` statically, but `recovery-bootstrap.js` imports `background.js` only *after* await points; that file contains `runtime.onMessage`, `runtime.onInstalled` and `alarms.onAlarm` registration. This **conflicts with the documented safest Firefox event-page registration pattern**. It is a reason to test wiring and adjust the implementation, **not proof of a donor release regression**.

- **Scope supersession retained:** every Stage 2 PJS/HTML-only AI phrase remains superseded by the accepted Stage 3 F1/F2 amendment. `src/` is part of the complete source fingerprint and tests.

Treat any session identifier as sensitive; redact from logs, reports, issue attachments, diagnostic exports and chat metadata; do not copy full transcripts by default.

### 11.2 Deterministic examples (test vectors, not executed)
